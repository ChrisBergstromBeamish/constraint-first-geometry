The Residuals — the open-gate attack list

This is the working list of every named residual in the 33-gate audit: the exact remaining work object inside each reached terminal, the kind of work that would strengthen it further, and its leverage. It is the companion to the gate scoreboard — the scoreboard says which terminal each gate reached and why; this page says what to strengthen next and in what order.

The goal is not to force closure. It is to reduce each residual to an honest acceptable terminal endpoint — reduced-to-anchor, reduced-to-axiom (if atomic), root-constrained (anchored residual), root-forced, or dissolved — or to return the exact reason it cannot. anchored IS closed (it rests on a named anchor floor) · selected ≠ forced · candidate ≠ settled · dissolved ≠ solved · floor ≥ 1. This is a frozen TOE candidate under honest audit: All 33 gates reach a closed terminal (derived-given-anchor, dissolved-given-root, measured-anchor, certified-irreducible, or reduced-to-axiom) — 26 resolved at +0 and 7 anchored at +1 — including BOTH deep roots (Scale and Shape). The rows below record each gate's reached terminal together with its named residual work objects, shown openly rather than rolled into hedges; the shared external frontier (the non-perturbative continuum / UV completion) remains a named, certified-irreducible wall.

How to attack one. Run the standing method: take the complete Shape · Scale · Granularity (a residual seen only under a truncated root is an artifact), apply the second-layer audit roots, build the map and its certificate, then the forcing certificate, then test against a Layer-1 observable. A residual closes only when a closed candidate class + every root leaves one target-blind rule that survives an observable test.
