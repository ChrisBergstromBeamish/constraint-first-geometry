The Tests

A candidate shape is worthless until it is checked against numbers nobody tuned it to hit. This page collects six specific tests run against the program's shape and its process — each with what was actually done, whether the check was run blind / both ways / independently, the honest result, and the data sources behind it. None of these are claimed as proof the shape is correct. Some are consistency checks (a green light means the machinery didn't quietly break known physics); some are genuine over-determination checks (more independent outputs than declared inputs); one is honestly blocked.

Read this before the six tests below. A "reproduce-known" result returns the same number with or without the new geometry — it is a consistency/equivalence demonstration, not a proof of the larger theory, and it does not claim to replace General Relativity, the Standard Model, or ordinary quantum mechanics. Where a test is genuinely blocked, it is reported as blocked, not quietly dropped or rounded up. See the Home page and The Process for how these checks fit into the larger discipline (freeze-before-compare, gate grading, ).

The six tests, at a glance

1. Dual GR, both ways Consistency

Solar light-bending worked two independent ways from the same shape, checked against Einstein's 1.75 arcsec and the Cassini PPN bound.

2. Two numbers → nine-plus Over-determination

Two declared flavor anchors (yt, |Vus|) lock the quark/lepton/neutrino chamber; nineteen-plus independent outputs come back, one flagged as the weakest link.

3. Early-universe blind predictions Blocked, honestly

A forward cosmology model gated on compute-before-compare discipline — currently BLOCKED_PENDING_NATIVE_LAMBDA, reported as blocked rather than skipped.

4. NASA-facing calculators 64/64 checks pass

A public suite of deep-space relativity calculators (Shapiro delay, Sagnac, light deflection, clock shift, optical-link budget) validated against 64 textbook, analytic, and public-mission benchmarks.

5. The quantum computer Simulated, design-stage

The same internal geometry used to design a fault-tolerant error-correction scheme and an accelerator-chip architecture — simulated results, not a built or benchmarked machine.

6. Gates × Constraints table Reference

A table of the eleven scoped-GUT gates against the Foundational Constraints, showing which constraint is load-bearing for which gate, and each gate's current honest status.

How to read every test on this page
