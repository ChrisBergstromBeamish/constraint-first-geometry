Gap-05-value — Lambda value (Tier-1 measured anchor): the gate anchor ledger

The honest one-line: Gap-05-value has a real, checkable win — the value of $\Lambda$ is recorded as a single directly measured number with zero reverse-engineering from the measured value (the frozen geometry produces no $\Lambda$ to fit), and the program's own best lever to fake a reduction was attacked and computed-refuted — but the value is a measured anchor, terminal as an anchor, never derived; on the ratified board the gate closes at exactly that honest terminal — MEASURED-ANCHOR · RESOLVED +0 — with the neighboring mechanism faces carried as shown residuals.

This page is the gate-specific instantiation of the anchoring method: it takes the master anchor and the four bridges and applies them, object by object, to one gate. Every exact thing Gap-05-value touches gets its own row — its status, what it is allowed to claim, and what it is forbidden to claim. It follows the same eleven-part shape as the canonical SG-4 ledger, adapted honestly to a gate whose nature is a measured anchor, not an obstruction-cancellation: there is no "anomaly ledger" here, and the gate's one closed leg is a no-reverse-engineering from the measured value guarantee, not $O(E_{\rm frozen})=0$.

6. The construction — the win is a refusal, made airtight

The value-leg has no derivation to show — that is the whole point. What it has is a set of rigorous, checkable structural facts and negative results that make "measured anchor, no reverse-engineering from the measured value" airtight rather than a bare assertion.

(1) The no-reverse-engineering from the measured value guarantee (the closed local leg). Most over-fit hazards exist because a theory has an internal quantity that could be slid toward the observed number. Here that lever does not exist: the frozen 13D geometry produces no $\Lambda$, so $$\mathcal C_{\rm Gap05}(E_{\rm frozen}) = \varnothing ,$$ i.e. the comparison set is empty by construction. This converts "we promise we didn't tune" into "there is structurally nothing to tune."

(2) The granularity negative control — failed by ~113 OOM (a diagnostic that the result is specific, not trivial). The program's deepest reduction lever elsewhere is granularity, which dissolves continuum (divergent) walls. Run as a deliberate control on the value — a finite supertrace at the natural granular scale $M_{\rm cutoff}=1/R_0$: $$\rho_{\rm vac}^{\rm gran} \sim M_{\rm cutoff}^4 = (1/R_0)^4 \quad\Longrightarrow\quad \text{lands } \sim 113\ \text{OOM from } (2.3\,\text{meV})^4,\ \text{and predicts no value.}$$ The value of $\Lambda$ is a finite wall, not a divergence; finite walls survive granularity. This is a genuine tripped negative control — the method correctly reporting "does not apply here," which is precisely what makes the win non-trivial rather than an artifact.

(3) The chamber-cancellation no-go $\Lambda$-R1 (the gate's one genuine negative win). The only positive corpus-internal idea was a sign-graded "chamber" sum over $K_6=SU(3)/T^2$. Attacked target-blind, it is refuted: a sign-grading can cancel a sum only if it acts on labels that distinguish terms, but the vacuum-energy operator is the identity / unit operator — grading-even and label-blind. The supertrace witness is honest-FAIL: ratio $0.58$ at $k=0$, $1.000$ at $k=1\text{–}8$ — the quantitative signature of the obstruction. Status THEOREM_REFUTED, banked at full strength. This is real recovered physics in the negative direction: the framework's own most promising lever for $\Lambda$ is dead, and the program says so.

The obstruction analog. There is no $O_{\rm Gap05}(E)=0$ to assert (this gate has no anomaly ledger). The gate's checkable content is the conjunction $$\big(\ \mathcal C_{\rm Gap05}(E_{\rm frozen})=\varnothing\ ,\quad \text{granularity-control} = \text{tripped}\ ,\quad \Lambda\text{-R1}=\text{REFUTED}\ \big),$$ all DERIVED-GIVEN-E, none of which derives the value. We do not assert that any of this closes the gate; the value remains a measured anchor and the neighbors remain open.

7. The sequestering theorem, split into three honest objects (L1 / L2 / L3)

The single phrase "sequestering" hides three different claims with three different statuses (Theorem 1, R5$'$-SEQUESTERING-ALL-ORDERS):

  1. (L1) Tree-level trace-drop. For a vacuum stress $T^{\rm vac}_{\mu\nu}=-V g_{\mu\nu}$, the trace-free combination vanishes identically, $$T^{\rm vac}_{\mu\nu}-\tfrac14 g_{\mu\nu}T^{\rm vac} = -V g_{\mu\nu}+V g_{\mu\nu} = 0 ,$$ for vacuum energy $V$ of any magnitude (including $O(M_{\rm Pl}^4)$). Status: DERIVED (tree-level). This hardens the catastrophe-half from conjecture to a tree-level theorem — at tree level only.
  2. (L2) The premise ALONE is insufficient at the quantum level. Under the premise, $\Lambda_{\rm grav}=\Lambda_0$ is an integration constant; an additive matter-loop shift $\delta V\sim M^4$ passes straight through, $$\Lambda_0 \;\to\; \Lambda_0 + \delta V \qquad(\text{the map is the identity}).$$ Status: DERIVED — NEGATIVE. The gate's own earlier slogan — "an integration constant has no beta function" — is TRUE BUT IRRELEVANT: there is no running coupling, yet the boundary value that replaces it is shifted additively. This is a correction to this gate's own prior reasoning; it must not be re-leaned on.
  3. (L3) All-orders sequestering, conditional. The Kaloper–Padilla augmented mechanism (rigid global scalars, $\theta R_{\rm GB}$, global 4-volume / flux constraints) makes the vacuum piece absorbable — but established in the action, not by an order-by-order proof, and conditional on a smoothness / non-degeneracy assumption $S$ (unproven). Status: CONDITIONAL / PARTIAL.

The decisive consequence for the value (R6$'$). The surviving residual $\Delta\Lambda$ is, in Kaloper–Padilla's own words, "radiatively stable, albeit with a value that is incalculable and should be set by measurement (just like the electron mass)" — a verified 1:1 relocation. So even the heaviest available construction does not derive the value; it relocates it to an incalculable boundary datum. This is the rigorous reason the value-leg is graded MEASURED ANCHOR and not DISSOLVED or REDUCED.

11. Anti-claims (what this page refuses to say)

  • Gap-05-value does not derive, predict, or explain the value of $\Lambda$. There is no model value; formally there is no internal comparator: $\mathcal C_{\rm Gap05}(E_{\rm frozen})=\varnothing$.
  • The measured value does not derive Gap-05 closed. An anchor terminates as an anchor — the ratified terminal is MEASURED-ANCHOR · RESOLVED +0, never DERIVED. Using a claimed-output as a measured anchor to close its own gate is the cardinal sin — refused here ($\Lambda$ enters as a measured input, never as a claimed output).
  • Granularity does not dissolve the value the way it dissolves continuum walls — the ~113-OOM control proves the opposite. And the ~113-OOM datum may not be promoted into "no reduction is possible" (that is a universal negative).
  • $\Lambda$ is not provably irreducible. The honest form is earned-irreducible under all known reductions, never provably so (Weinberg-OPEN).
  • The chamber-cancellation route does not derive $\Lambda$ — it is computed-refuted ($\Lambda$-R1, unit-operator obstruction).
  • The "an integration constant has no beta function" slogan is true-but-irrelevant (L2) and must not be re-leaned on.
  • The frozen-branch hashes are audit anchors; they do not validate the physics.
  • The value is not a pristine T1 invariant — it is T3 (ΛCDM-laden) pending its co-consumption ledger.
