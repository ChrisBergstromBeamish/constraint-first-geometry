Source Registry

Every formula, constant, scenario anchor, and validation case in the Relativistic Optics Lab cites one or more source_ids from shared/source_registry.json. No prose-only sourcing is permitted. This page groups the registry by source type so reviewers can tell at a glance whether a value rests on an exact SI definition, a public ephemeris snapshot, a textbook benchmark, a public mission fact, an experimental constraint, or a user-declared assumption.

How types are used. authoritative_constant = SI / CODATA / IAU / IERS / NGA exact or recommended values; public_ephemeris = JPL DE-series or Horizons snapshots; textbook_benchmark = standard reference texts; public_mission_fact = publicly disclosed mission parameters (never proprietary); public_experimental_support = published measurement results used as cross-checks; user_assumption = values entered at runtime, never validated independently.
