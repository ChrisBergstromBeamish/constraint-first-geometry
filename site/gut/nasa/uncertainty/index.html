Assumptions

    Limits and "not included"

    • Linear sensitivity assumes the function is locally linear and the inputs are independent. Correlated uncertainties require a full covariance matrix.
    • Monte Carlo with N = 10⁴ has finite-sample noise on tail percentiles (p5, p95). Increase N for tighter percentiles.
    • The Box–Muller normal sampler returns one draw per uniform pair — no antithetic / Latin-hypercube variance reduction. TODO: optional Latin-hypercube sampling
    • Per-input distributions are sampled independently. No copula or correlation. TODO: correlation matrix support
    • Scenarios use the calculator formulas in shared/shared.js; same approximation limits apply (weak-field PPN, paraxial, etc.).
