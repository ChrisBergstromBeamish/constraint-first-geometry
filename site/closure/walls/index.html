Closure paths — one routing per wall

For each of the 19 frontier walls, this folder records a closure path built with the /closure routing protocol: the wall is routed to one of the five legitimate endpoints — derive · reduce-to-root · dissolve · anchor · wall-record — with banked wins separated from the missing object, the terminal status assigned, the residual named, and anti-claims that stop status inflation. Where a wall cannot honestly be reduced or dissolved, it is routed instead to DERIVE / ANCHOR / OPEN-ANCHORED / WALL-RECORDED with the remaining gap stated explicitly.

The discipline, kept on every page: dissolved ≠ solved · selected ≠ forced · given-E ≠ derivation-of-E · measured-anchor ≠ derived value · wall-recorded ≠ physics-closed · a bounded local certificate is not global completion. No wall is claimed physics-CLOSED.

How to read a closure path

Each file states, for its wall: the routing decision, the deep-root link(s), the honest reduce/dissolve verdict (including where reduction or dissolution is not legitimate), the steps to the endpoint, a target-blind success criterion / falsifier, the terminal status, the residual work, and the anti-claims.
