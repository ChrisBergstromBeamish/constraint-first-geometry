The terminal-anchored principle

Every gate carries two independent statuses:

  • Anchor status — is the gate's ledger complete? (Does every object it touches have a root link, a master-anchor link, an allowed claim, a forbidden claim, and a named residual?) All 33 gates are ANCHOR-CLOSED.
  • Physics status — the honest physics grade. No gate is physics-CLOSED. Some have reached their legitimate per-gate endpoint (TERMINAL-ANCHORED); the rest own a bounded, finite, falsifiable piece of open work (OPEN-ANCHORED).

A TERMINAL-ANCHORED gate is one whose only residual is (i) a dissolved unicorn, (ii) a shared global wall it does not own, (iii) a named declared axiom, or (iv) a measured anchor — none of which is a per-gate deliverable. An OPEN-ANCHORED gate still owns a concrete wall it can, in principle, push.

A unicorn — "no competitor anywhere / unique across all possible mathematics / no future theory could do better / proven absolutely irreducible" — is a universal negative, unprovable in principle for any object in any field. A unicorn is never a wall. It is dissolved as a non-target, and the bounded, in-grammar version is recorded as the real wall.
