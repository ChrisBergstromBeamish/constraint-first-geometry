The given-E / bundle-uniqueness wall

Kind: PER-GATE-BOUNDED (finite, owned work-package). One honest sentence: the open object is a bundle-uniqueness theorem showing that the weight on the frozen carrier returning the index $-3$ is the unique minimal admissible weight — selecting the three-generation count without invoking "three generations" and without treating the observed spectrum $E$ as a derived output rather than a given input.

This page presents the wall under the terminal-anchored principle: anchored ≠ closed. Every gate that touches it is anchor-closed; none is physics-closed. The wall has two faces that must never be conflated: a bounded, ownable sub-target (the bundle/weight uniqueness over a declared admissibility class) and a terminal anchor (the spectrum $E$ itself, which no known principle forces). The first is genuine open work; the second is honestly named as a measured anchor, and the universal-negative version ("$E$ forced across all geometries") is a dissolved unicorn, never the wall.

What is missing

The family count is computed as a rigid topological index on the frozen carrier $K_6 = SU(3)/T^2$. By Borel–Weil–Bott, the holomorphic Euler characteristic of the matter line bundle is integer-valued and deformation-proof:

$$\chi(K_6,E) = \sum_i (-1)^i \dim H^i(K_6,L_\lambda) = -3, \qquad |\chi(K_6,E)| = 3 = \text{number of generations,}$$

and the chirality fold on the orbifold $S^1_Y/\mathbb{Z}_2$ supplies the Atiyah–Patodi–Singer boundary index $(n_L,n_R) = (+3,\,0)$ (against the handedness-neutral bare-circle control $(+3,+3)$). This local magnitude leg is graded DERIVED-GIVEN-E — the strongest honest status, not physics-CLOSED — and its obstruction vanishes only given $E$:

$$O_{\rm SG3,local}(E) = \big(\chi(K_6,E)+3,\ (n_L,n_R)-(+3,0)\big) = 0 .$$

What is missing sits strictly beyond the magnitude. The bundle whose Chern data returns $-3$ is $E$ itself — the observed Standard-Model chiral content fed in as input — so the rigid integer certifies "this geometry+bundle yields three families, given the particles we observe," not a derivation of three from the geometry alone. The precise missing object is the bundle-uniqueness theorem, named in the SG-3 ledger as AXIOM-MIN-WEIGHT-LIFT:

$$\textbf{(W5 target)}\qquad \text{enumerate the }K_6\text{ weights compatible with the }\mathbb{Z}_6\text{ congruence } q \equiv 3z_2 - 2z_3 \ (\mathrm{mod}\ 6);\ \text{prove minimality singles out a unique weight with } |\chi| = 3\ \textbf{value-blind.}$$

Until that lands, the full gate obstruction is not asserted to vanish — only its local face is:

$$O_{\rm SG3}(E) = \big(O_{\rm uniqueness}(E),\ O_{\rm carrier\text{-}tiebreak}(E),\ O_{\rm sign}(E),\ O_{\rm local}(E)\big),\qquad O_{\rm SG3}(E) \neq 0 .$$

There are three distinct gaps in $O_{\rm SG3}$ that this wall holds open:

  • Bundle/weight uniqueness — the weight returning $\chi=-3$ is selected inside a declared admissibility class, not proven the unique admissible one (SG-3 residual R3, AXIOM-OPEN, highest leverage).
  • Given-E conditioning — the bundle is $E$; using $\chi=-3$ to "force" $E$ would be circular (SG-3 residual R1, closeable only via R3).
  • Carrier tie-break — $K_6$ (6D) beats the cheaper $\mathbb{CP}^2 = SU(3)/U(2)$ (4D) on the family count only by paying $+2$ dimensions under an anti-fitting tie-break that is aligned with the three-generation target (SG-3 residual R2, FLAGGED). Both carriers in fact return three only after a bundle choice — $\mathbb{CP}^2$ via the Spin$_c$ index $\tfrac{r(r+1)}{2}$ with $r=2$, and $K_6$ via the BWB weight $(1,0)$ — so neither forces "3" from the bare carrier alone.

What would close it — or why it is terminal

This wall is two objects in one frame, and they close differently.

The bounded half — bundle/weight uniqueness (closeable in principle). The closure is a finite, target-blind Lie-theoretic computation, established without using the known generation number as input:

  • (A) enumerate the $K_6$ weights compatible with the $\mathbb{Z}_6$ Tong-congruence lattice;
  • (B) apply BWB to each, building the map weight $\mapsto \chi$;
  • (C) test whether minimality singles out a unique weight giving $|\chi|=3$ without invoking "three" and without consulting the LEP light-neutrino count $N_\nu = 2.984 \pm 0.008$.

Success criterion (sharper-OPEN → AXIOM-CLOSED): if a value-blind minimality criterion yields the $|\chi|=3$ weight uniquely, the bundle is forced inside the declared class and the given-E conditioning (R1) lifts at last. The realistic ceiling is AXIOM-CLOSED — no DERIVED-CLOSED is promised, because the spectrum $E$ at the bottom stays charged.

What a refuting result looks like (equally valid — a published finding): a strictly-lower-cost admissible weight is exhibited with $\chi \neq -3$. Then the bundle was three-selected — chosen because it gives three — and the uniqueness claim is withdrawn. The companion carrier-tie-break refutation: re-run the selector with the three-generation target masked; if $K_6$ beats $\mathbb{CP}^2$ only because it yields 3 (and not on "the count must be a rigid integer, not a continuous modulus" alone), the $+2$-dimension payment is confirmed target-aligned.

The terminal half — the spectrum $E$ (anchored, not closeable). The honest endpoint for $E$ is to declare it the irreducible measured anchor of the SHAPE root, terminal-by-anchoring. No known principle forces exactly three chiral generations as the unique admissible family count: anomaly-freedom is a settled filter with infinitely many solutions. The floor stays at $\ge 1$ anchor ($E$ here), by design, forever — anchored ≠ closed.

The guard against a fake close is the no-target-loading rule: a closure path that introduces a new target-aligned criterion (e.g. "pick the weight that gives three") has relocated the input, not removed it. The minimality criterion must be writable without knowing that three should win.

Falsifier

The pre-registered falsifier is the REFUTED-BUNDLE-SELECTED outcome above: a target-blind enumeration in which a strictly-lower-cost admissible $K_6$ weight returns $\chi \neq -3$. Such a result kills the bundle-uniqueness claim directly — it demonstrates the index-$(-3)$ weight was selected because it reproduces the known count, so the minimality argument cannot be claimed to derive it. (The carrier-tie-break sub-falsifier: the target-masked selector run keeps $K_6$ over $\mathbb{CP}^2$ only when three is the answer.)

Anti-claims (what must never be said about this wall)

  • Not "three generations are derived (from nothing)." The index is computed with $E$ as input; $E \in \ker O_{\rm SG3,local}$, not $\ker O_{\rm SG3,local} = \{E_{\rm SM}\}$. The honest hook is "given the particles we observe."
  • Not "three is forced across all geometries." That is a universal negative, unprovable in principle for any theory; only this geometry+bundle is certified.
  • Not "anomaly cancellation selects the Standard Model." Anomaly-freedom is a filter, not a selector: vector-like additions $R \oplus \bar R$ cancel every anomaly, so infinitely many spectra pass. The claim that $E$ is forced by anomaly-freedom + minimality is REFUTED.
  • Not "the bundle/weight is unique." It is only selected inside a declared admissibility class (R3); uniqueness is exactly the missing theorem.
  • Not "$K_6$ is forced for the family count." $K_6$ is the unique clean $SU(3)$ carrier for the gauge sector (abelian-isotropy uniqueness, $C_{SU(3)}(T^2)=T^2$); for the count it pays $+2$ dimensions over $\mathbb{CP}^2$ under a flagged target-aligned tie-break. The legitimate gauge result must not launder the family-count tie-break.
  • Not "left-handed, no surviving mirror" as a settled chirality output. Only the magnitude $3$ and the one-sidedness $n_R=0$ are convention-independent; the sign $-3$ rides an unpinned $\mathrm{Pin}^\pm$ orientation bit whose default convention is in fact the wrong sign for the downstream leptogenesis target.
  • Not "the spectrum $E$ is forced / derived." $E$ is a MEASURED ANCHOR, terminal-by-anchoring; "$E$ is forced" is refuted, and the absolute "$E$ unique across all mathematics" is a dissolved unicorn, never the wall.
  • Not "local magnitude closure is whole-gate closure." $O_{\rm SG3,local}=0$ does not imply $O_{\rm SG3}=0$.
