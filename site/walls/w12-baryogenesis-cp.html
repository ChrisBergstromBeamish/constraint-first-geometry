The baryogenesis CP-source wall

Kind: PER-GATE-BOUNDED (a finite, owned work-package — plus a live, pre-registered falsifier). One honest sentence: the open object is the rephasing-invariant high-scale CP source of leptogenesis — a Jarlskog-type invariant $I_{CP}[Y_\nu,M_R]$ together with the heavy Majorana spectrum $M_R$ and the absolute neutrino Yukawa norm — none of which the frozen geometry yet supplies, with the additional honest twist that the geometry's default high-scale phase comes out with the wrong sign for generating the observed asymmetry.

This page presents the wall under the terminal-anchored principle: anchored ≠ closed. The gate that owns it, Gap-10/BG-10, is anchor-closed; it is not physics-closed. What is rigorous here is a negative statement (the bare geometry sources exactly zero asymmetry) plus a pair of firewall theorems and a pre-registered falsifier — a bounded, in-grammar work-package, never a derivation of the measured $\eta_B$.

What is missing

The cleanest fully-shown fact of the gate is a closed negative. The frozen geometry's only named direct holomorphic factor at the order-three modular fixed point $\tau=\omega=e^{2\pi i/3}$ is

$$q_1(\omega)=e^{2\pi i\omega}=e^{-\pi i}\cdot e^{-\pi\sqrt3}=-\kappa,\qquad \kappa=e^{-\pi\sqrt3}>0,$$

which is real (its phase is $\pi$, not $\pi/4$; numerically $\mathrm{Im}\sim 6\times10^{-18}$). If the CP-source entry is proportional to it, $H_{12}\propto q_1(\omega)\in\mathbb{R}$, then

$$\mathrm{Im}\big(H_{12}^2\big)=0\ \Longrightarrow\ \varepsilon_1\propto\mathrm{Im}\big(H_{12}^2\big)=0\ \Longrightarrow\ \eta_B=0.$$

So the bare geometry, as frozen, sources exactly zero matter–antimatter asymmetry. This is a proven obstruction (status DERIVED-GIVEN-E), not a value of $\eta_B$. The fixed point $\tau=\omega$ fixes only the magnitude $|H_{12}|\propto\kappa$; it contributes zero CP phase.

What is missing is the entire object that decides a non-zero number. The textbook flavored-leptogenesis chain is assembled correctly and halted honestly: every stage is the standard formula and every one terminates at a genuinely-missing high-scale numeral,

$$\varepsilon_1=\frac{1}{8\pi(Y^\dagger Y)_{11}}\sum_{j\neq1}\mathrm{Im}\big[((Y^\dagger Y)_{1j})^2\big]\,f\!\left(\frac{M_j^2}{M_1^2}\right),\qquad \eta_B=7.04\,Y_B,\quad Y_B=\frac{28}{79}\,\kappa\,\frac{\varepsilon_1}{g_*^s},$$

with $g_*^s=106.75$. The light side is fully pinned — the Davidson–Ibarra mass factor $(m_3-m_1)=5.0150\times10^{-2}$ eV is a real, reproducible number — yet $\varepsilon_1$ is still identically zero, which is what makes the zero-CP result a genuine arithmetic obstruction rather than a numerical accident. The precise missing objects are:

  • The high-scale CP phase / the $\sigma_\nu$ sign bit (highest leverage). The continuum CP phase compresses to one mod-8 spin-$\mathbb{C}$/Pin bit. The default fixed by the spin-$\mathbb{C}$ index $\chi(K_6,E)=-3\ (\equiv 5\bmod 8)$ gives $e^{2\pi i(-3)/8}=e^{-3i\pi/4}=-e^{i\pi/4}$ — an eighth-root phase in the same family as the needed $e^{i\pi/4}$, but with the wrong sign. Status AXIOM-OPEN / RECIPE-ABSENT.
  • The heavy Majorana spectrum $M_R=(M_1,M_2,M_3)$ — the single binding wall. Named mechanism, no formula; the only figure is a band $M_R\sim 10^{9}$–$10^{14}$ GeV straddling all three flavor regimes. The candidate $M_R=\kappa\,M_U$ is off by $\sim 231\times$. Status OPEN / RECIPE-ABSENT.
  • The CP-invariant form $I_{CP}[Y_\nu,M_R]$. A Jarlskog-type rephasing-invariant functional whose closed form and invariance proof are writable now, but which cannot be evaluated without the recipe-absent $M_R$ and the absolute $Y_\nu$. Status AXIOM-OPEN / computation debt.
  • The flavored kinetics (CC-2…CC-5): the RIS-subtracted $\Delta L=2$ washout, the $N_2/N_3$ damping ledger, the density-matrix flavor evolution, and the final $B{-}L\to\eta_B$ assembly. Status OPEN / computation debt — 0 of 4.

The single sharpest missing artifact is therefore the rephasing-invariant high-scale CP source $I_{CP}$ together with the $M_R$ spectrum recipe, computed target-blind — never pinned from the measured $\eta_B$.
