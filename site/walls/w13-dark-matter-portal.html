The dark-matter portal-normalization wall

Kind: PER-GATE-BOUNDED (a finite, owned work-package). One honest sentence: the same frozen $13\mathrm{D}$ shape that recovers the Standard Model also localizes and stabilizes a dark-matter candidate that nobody fitted to the data — structurally selected $17$ of $18$ times — but the one number the relic abundance rides on, the portal normalization $N_{\rm portal}$ (a finite, in-principle-computable wavefunction-overlap integral), is not yet evaluated, so the gate owns a bounded magnitude debt, not a closure.

This page presents the wall under the terminal-anchored principle: anchored ≠ closed. The gate that owns it is anchor-closed; it is not physics-closed. The wall is a bounded, in-grammar work-package with named residuals and a clean refute-only falsifier — and the candidate's identity and stability do not, by themselves, fix any abundance.

What is missing

The frozen geometry contains an $S^1_Y/\mathbb{Z}_2$ factor (the hypercharge circle modded by a $\mathbb{Z}_2$ orbifold), whose boundary fixed point localizes a zero-mode — the C-iii state — with three structural quantum numbers:

$$\text{C-iii}:\quad \mathbb{Z}_2\text{-odd},\qquad Y=0,\qquad (\text{color- and electrically-neutral}).$$

That state is a genuine given-$E$ win: $\mathbb{Z}_2$-odd parity (the orbifold action itself, fixed for independent reasons — not an imposed dark parity) forbids decay to any final state built entirely from $\mathbb{Z}_2$-even Standard-Model fields, and $Y=0$ keeps any portal coupling renormalizable. The identity + stability leg is discharged given $E$:

$$\big[\mathbb{Z}_2\text{-odd}\big]\wedge\big[Y=0\big]\ \Rightarrow\ \text{(stable, dark, renormalizable-portal-admitting candidate)},\qquad O_{\rm Gap11,local}(E_{\rm frozen})=0.$$

What is missing is everything that needs a magnitude. The candidate carries no abundance number. The full gate obstruction adds a magnitude-debt family the local leg does not close:

$$O_{\rm Gap11}(E)=\big(O_{\rm operator},\,O_{N_{\rm portal}},\,O_{\rm relic}(T_{\rm RH}),\,O_{\rm adjudication}\big),\qquad O_{\rm Gap11}(E_{\rm frozen})\ne 0\ \text{(asserted).}$$

The precise missing objects are:

  • The portal operator — the lowest-dimension, $\mathbb{Z}_2$-odd-preserving coupling that connects C-iii to the thermal bath. It is currently UNNAMED; you cannot normalize an operator you have not named.
  • The portal normalization $N_{\rm portal}$ — a finite, fully-specifiable but UNRUN wavefunction-overlap integral on the boundary geometry, reduced $13\mathrm{D}\to 4\mathrm{D}$:

$$N_{\rm portal}\ \propto\ \int_{S^1_Y/\mathbb{Z}_2}\psi_{\rm C\text{-}iii}(y)\,\psi_{\rm bath}(y)\,(\text{geometry factors})\,dy .$$

It is an explicit numerical computation, not an argument that can be carried to a value by reasoning alone. There is no first-principles hash for $N_{\rm portal}$ — no frozen object exists for it.

  • The relic abundance $\Omega_{\rm DM}h^2$ — the standard freeze-in Boltzmann quadrature, OPEN / downstream-gated on $N_{\rm portal}$ and a frozen reheating temperature:

$$\Omega_{\rm DM}h^2\ \propto\ \int\big(\text{production rate}(N_{\rm portal},T)\big)\,dT\quad\text{over the }T_{\rm RH}\text{ band}.$$

The mechanism is freeze-in, not freeze-out: the candidate is never in thermal equilibrium; it is slowly populated by the feeble portal. No value is asserted anywhere.

The structural compression (the key insight). The same coefficient $N_{\rm portal}$ sets both the production rate (the relic abundance) and the elastic scattering rate (the direct-detection cross-section). So the gate is structurally one missing derivation with two downstream consumers and one experimental adjudicator.

The structural fork comes first. Whether $N_{\rm portal}$ is even the right object is itself open. On one branch the abundance is geometric and $N_{\rm portal}$ is a non-object; on another it is only a correction; on a tower-co-carry branch the answer routes into the recorded KK-overclosure machinery. The fork must be resolved before $N_{\rm portal}$ is treated as the single block. The single sharpest missing artifact is therefore: resolve the inventory fork without reference to the measured value, then — only on the surviving branch — evaluate $N_{\rm portal}$, never tuning it to the data.

What would close it — or why it is terminal

This is a bounded, owned work-package, not a unicorn. Each residual is a concrete, finite computation performed without reference to the measured value. The hard discipline throughout: never tune to the measured floor $\Omega_{\rm DM}h^2\approx 0.12$ (Planck) — that is the single comparison target, used once, post-freeze, and backing any coefficient out of $0.12$ is the prohibited anti-fitting move.

  • Evaluate $N_{\rm portal}$ (the block). Compute the overlap integral via the dimensional-reduction conventions, without reference to the measured value, tracking the normalization-convention hazard. Success: the integral evaluates with no fudge and the downstream relic integral lands near $0.12$ post-freeze; else a named AXIOM-PORTAL-NORMALIZATION if it is verified to yield a value; else the realistic terminus, OPEN as an explicit numerical computation — not an axiom one can reason to.

Success criterion (the honest endpoint): Gap-11 moves from candidate-recorded, gate-open toward a frozen prediction — and even then, only given $E$ and a frozen $T_{\rm RH}$, and only by comparing to $0.12$ once, never by tuning to it. The legitimate interim terminal is to name the standing posits as declared axioms and stop. One claim that might look like a shortcut is not available: that the same selection criterion picking the dark state ($17/18$) also governs the operator inventory. "REFUTED AS STATED" means the strong state→operator transfer is not licensed — it does not mean the candidate was disproven. The gate is therefore honestly larger, not more closed.

Falsifier

The wall carries a refute-only experimental adjudicator. Because $N_{\rm portal}$ sets both the relic rate and the elastic-scattering rate, a recorded spin-independent direct-detection forecast already exists:

$$\sigma_{\rm SI}\sim 10^{-55}\text{–}10^{-60}\,\mathrm{cm}^2,$$

which sits roughly $6$–$11$ orders of magnitude below the neutrino floor $\sigma\sim 10^{-49}\,\mathrm{cm}^2$ (the irreducible coherent-neutrino-scattering background). The asymmetry is exact and pre-registered: any direct-detection signal above this band kills the minimal candidate, but no null result can confirm it — the forecast lies below the floor where no terrestrial experiment can probe. That asymmetry is an observation limit on all of physics for a portal this feeble, not a defect of this theory. The $\sigma_{\rm SI}$ point value within the band is itself gated on $N_{\rm portal}$; only the band and the refute-only test are recorded now.

A separate, recorded coupling $\lambda_p(0.12)\sim 10^{-11}$ exists as a role-ambiguous feeble coupling. It is not asserted to be $N_{\rm portal}$ — assuming that identity would back the normalization out of $0.12$, the prohibited anti-fitting move — and is exported to the owner as an open question, not a result.

Anti-claims (what must never be said about this wall)

  • Not "Gap-11 derives the dark-matter abundance." No $\Omega_{\rm DM}h^2$ value is asserted anywhere; the relic integral is gated, not run, and $N_{\rm portal}$ has no assertable value. The candidate carries no abundance number.
  • Not "$N_{\rm portal}$ has a value" / "computed from $0.12$." It is a fully-specifiable but UNRUN overlap integral; reasoning cannot carry it to a number, and backing it out of $0.12$ is forbidden anti-fitting.
  • Not "$\lambda_p(0.12)\sim 10^{-11}$ is $N_{\rm portal}$." That identity is unasserted (the $\kappa^3/\pi$ anti-pattern); it is an exported question.
  • Not "the KK-overclosure PASS fixes the abundance." The bound $\Omega_{\rm KK}\le 1$ is one-sided — a necessary viability bound, never a sufficient abundance determination; it must never be upgraded from PASS to abundance-determined.
  • Not "the $17/18$ selection is a certificate / a prediction." It is a decision-grade audit at selector-CANDIDATE grade, frozen before any abundance comparison; never re-scored from memory.
  • Not "one geometric rule selects both the particle and its portal operator." REFUTED AS STATED by two verified theorems; only the state-side selection is established.
  • Not "a null direct-detection result confirms the candidate." The forecast is refute-only; it sits $\sim6$–$11$ OOM below the neutrino floor, so no null can confirm it.
  • Not "Gap-11 derives $E$" or "Gap-11 fixes $T_{\rm RH}$." The candidate is read off this $E$; the reheating band is inherited from Gap-09.
  • Not "the frozen hashes validate the physics." dcc66f1b2685 / a5b1e6f9d951 are audit anchors certifying which object was tested — and there is no hash for $N_{\rm portal}$.
  • Not "local established structure is whole-gate closure." $O_{\rm Gap11,local}(E_{\rm frozen})=0$ does not imply $O_{\rm Gap11}(E_{\rm frozen})=0$.
