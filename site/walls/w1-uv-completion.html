The UV-completion / strong-coupling quantum-gravity wall

Kind: SHARED-GLOBAL — a frontier problem no single gate owns.

One line: the program supplies the graviton operator cleanly, but a constructive, non-perturbative UV completion (or a defensible non-continuum replacement) of the interacting graviton above the cutoff is not exhibited — by this program or by any other — so every gate that touches the strong-coupling regime is terminal-anchored / physics-open here, sharing one wall rather than each owning a private hole.

The terminal-anchored principle, applied to W1: anchored ≠ closed. The per-gate endpoint is to name this wall precisely and pin each gate to its anchor set — not to claim closure. Full closure of quantum gravity is a shared frontier object; it is not a per-gate deliverable, and no gate on this page is labelled CLOSED.

What is missing

The precise missing object is a constructive, target-blind, non-perturbative UV completion of the interacting graviton on the frozen background — or a defensible non-continuum replacement for it. On the background $\mathcal{M}_4\times K_6\times S^2\times S^1_Y/\mathbb{Z}_2$ with $K_6=SU(3)/T^2$, de-Donder (harmonic) gauge-fixing of the metric fluctuation $h_{MN}$ supplies the Lichnerowicz-type operator $$L_{\rm grav}=-(\nabla^2+E),$$ whose 4D massless spin-2 mode is the graviton, with the Kaluza–Klein tower above it. The operator is in hand; what is missing is everything that decides the theory above the cutoff, where the perturbative series in $G_N E^2$ ceases to converge: $$O_{\rm 5C}(\mathfrak{B}_{\rm active})\;=\;\text{a constructive, non-perturbative UV completion / strong-coupling closure of the interacting graviton}\;\;\textbf{— no route exhibited.}$$

Concretely, the missing object splits into two genuinely different predicates that must never be merged: $$\text{Predicate A: }\exists\;\text{a truncation-independent non-Gaussian fixed point (or defensible non-continuum replacement)}\quad(\textbf{OPEN / global wall}),$$ $$\text{Predicate B: reality requires no }a\to 0\text{ continuum limit}\quad(\textbf{DISSOLVED, one value-free axiom — does not exhibit A}).$$

Adopting the cost floor as a root principle (AXIOM-COSTFLOOR) dissolves one class of high-energy idealizations — the $a\to 0$ Seeley–DeWitt counterterm tower $a_8, a_{10},\dots$ — Lorentz-invariantly, because the floored quantity (cost / action / information) is a scalar. But DISSOLVED $\ne$ SOLVED: dissolving the continuum class makes a fixed point unnecessary to take an $a\to 0$ limit; it does not supply one. Of the eleven standing walls the cost floor is checked against, exactly 1 dissolves and 10 are untouched — and the finite $a_6$ datum is among the untouched, because it exists term-by-term at any spacing and identically in the continuum (there is no $a\to 0$ infinity inside it).

A frequently-mistaken near-object is the sixth Seeley–DeWitt heat-kernel coefficient $a_6$. It is the missing object for UV consistency, never is the completion: even a flawless, finite, positive $a_6$ certifies one coefficient in the unbounded operator ladder $$a_6 < a_8 < a_{10} < \cdots$$ (the scope firewall), and one coefficient cannot settle strong-coupling behaviour. $a_6$ is necessary, not sufficient.

What would close it — or why it is terminal

W1 is a shared global wall, so its closure is not a per-gate deliverable. There is one shared construction to attempt — built once, not gate-by-gate:

  • The fixed-point construction (Predicate A). Using exact-renormalization-group / Wetterich-flow machinery on $L_{\rm grav}$ and the frozen chamber data, either exhibit a truncation-independent non-Gaussian fixed point (with a non-tachyonic Kaluza–Klein spectrum running UV $\to M_*\approx 6.01\times 10^{16}$ GeV) or prove its non-existence within asymptotic safety. Both outcomes close it. A fixed point within a declared truncation is evidence, not a certificate — and current functional-RG evidence trends against the naive truncation route, which sharpens the wall rather than refuting it. The requirement is two structurally-different routes, not two runs of one engine.

A refuting result is a valid close: uncontrolled high-energy amplitudes, a negative-norm physical state above the cutoff, a regulator-dependent conclusion, or a proof that no such fixed point exists on this geometry would each terminate the question.

Why it is terminal-anchored short of that. The honest grade is layered: the operator is supplied (DERIVED-GIVEN-E, as structure); the linearized legs are CERTIFICATE-CONDITIONAL on UQF-9, one floor below; the strong-coupling completion is OPEN everywhere. A UV-complete, strong-coupling quantum theory of gravity is open for strings, asymptotic safety, loop approaches, and this program alike. The nearest tractable handle is P0 — does the gravitational sector have its own minimal length, or does it inherit the colour scale $R_0$? The established result T-DEEP found $R_0$ to be a pure colour/gauge object with $R_0/\ell_{\rm Planck}\sim 194$, so every finite-grain attempt at 5C relocates onto UQF-9; there is no finite-grain shortcut, and the wall is genuine.

Falsifier

W1 itself is a frontier wall, not a single quantitative claim, so it carries no single pre-registered numeric falsifier of its own. The decision-grade tests live one floor below and could refute the conditional legs that ride on W1:

  • Positivity functional on the computed $a_6$. Once the $d=13$ graviton-minus-ghost trace $\mathrm{tr}[a_6]$ is computed target-blind and a positivity functional $P$ is selected, the test $P(\mathrm{tr}[a_6])\ge 0$ is decision-grade: a result $P(\mathrm{tr}[a_6])<0$ refutes the linearized graviton certificate (5A/5B) at decision grade. (At present $P$ is unselected and the trace is uncomputed — the test is a falsifier in principle, not yet runnable; no sign may be asserted.)
  • Above-cutoff causality. The measured graviton zero-mode speed bound $\lvert c_m-c\rvert/c < 10^{-15}$ (GW170817 / GRB170817A, two detector triggers $\sim 1.7$ s apart) constrains the zero-mode only; it cannot be promoted across the cutoff. A demonstrated above-cutoff causality violation in the strong-coupling sector would falsify the inherited UQF-14 leg.

Anti-claims (what must never be said about this wall)

  • A finite or positive $a_6$ is NOT the UV completion. It passes one heat-kernel consistency coefficient among an unbounded tower; relabelling "$a_6$ computed" as "5C closed" relocates the wall and is refused.
  • No gate "closes quantum gravity." W1 is OPEN, shared by every approach. No gate on this page is labelled CLOSED.
  • No non-Gaussian / asymptotically-safe fixed point has been exhibited. Candidate fixed points exist only within declared truncations; a truncation fixed point $\not\Rightarrow$ closure.
  • The cost-floor reframe does not SOLVE UV completion. It dissolves one continuum-limit class, Lorentz-invariantly; it exhibits no fixed point, computes no $a_6$, and leaves the finite $a_6$ and the fixed-point wall untouched. AXIOM-COSTFLOOR is declared and value-free, not atomic.
  • No $a_6$ value, sign, or partial may be asserted. The dimensionful bulk magnitude is ill-posed at odd $D=13$ (the $-2.818\times 10^{94}\,\mathrm{GeV}^6$ number was retracted); the dimensionless coefficient $C\approx-6.39$ is unreproduced and must not be fabricated.
  • "No future theory could UV-complete gravity better than ours" is a unicorn, not a wall. A universal negative over all possible mathematics is unprovable for everyone; it is dissolved as a non-target. The bounded, in-grammar object — the missing constructive completion / fixed point — is the real wall.
  • The frozen-branch hashes dcc66f1b2685 / a5b1e6f9d951 are audit anchors that certify which object was tested; they do not validate the physics, and the frozen geometry is selected, not proven uniquely forced.
